# EMI Calculator Theme Update

## Overview
Updated the EMI Calculator with a modern, fresh theme based on teal and amber colors, replacing the previous blue/purple and red color scheme.

## Theme Colors

### Primary Colors
- **Teal/Cyan**: Main brand color for interactive elements and principal amounts
  - Primary: `#14b8a6` (teal-500)
  - Darker: `#0d9488` (teal-600)
  - Darkest: `#0f766e` (teal-700)
  - Light: `#99f6e4` (teal-200)
  - Lightest: `#f0fdfa` (teal-50)

- **Amber**: Accent color for interest amounts
  - Primary: `#f59e0b` (amber-500)

### Key Changes

1. **Input Section**
   - Gradient background from teal-50 to cyan-50
   - Teal border and shadow effects
   - Range sliders with teal gradient thumbs
   - Enhanced hover states with shadows

2. **Summary Cards**
   - Teal borders and accents
   - Main EMI card: Teal gradient background
   - Improved hover effects with teal shadows
   - Values displayed in teal color

3. **Payment Breakup Chart**
   - Principal: Teal (`#14b8a6`)
   - Interest: Amber (`#f59e0b`)
   - Enhanced shadow effects

4. **Amortization Schedule**
   - Teal headers and borders
   - Principal amounts in teal
   - Interest amounts in amber
   - Improved scrollbar styling with teal colors

5. **Dark Mode Support**
   - Darker teal backgrounds (`#134e4a`, `#115e59`)
   - Teal accents for borders and highlights
   - Maintains excellent contrast and readability

## Visual Impact
- Modern, fresh appearance
- Professional yet approachable
- Excellent color contrast for accessibility
- Cohesive color scheme throughout
- Distinct visual separation between principal and interest
